# Keycloak theme (reference)

Reference Keycloak **login** theme for MOSIP (FreeMarker under `theme/base/login/`).

This is not a Maven module. Overlay or copy the `theme/` tree into your Keycloak distribution as documented for [MOSIP Keycloak](https://docs.mosip.io/1.2.0/id-lifecycle-management/supporting-components/keycloak).

```text
keycloak/
└── theme/base/login/     login FTL, messages, resources
```

Upstream Keycloak images and MOSIP customizations: [github.com/mosip/keycloak](https://github.com/mosip/keycloak/tree/master).
